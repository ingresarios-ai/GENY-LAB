Las 7 Actividades Core

Cada actividad se desbloquea al completar la anterior. El usuario avanza por 3 fases.

🧬

1. ADN Financiero

Test que revela el arquetipo financiero del usuario y su sombra (debilidad).

FASE 1: DESPERTAR
🐜

2. Gastos Hormiga

Calculadora que descubre la fuga mensual/anual en gastos invisibles.

FASE 1: DESPERTAR
🌡️

3. Termostato

Mide el "techo invisible" de riqueza que la mente del usuario le impone.

FASE 1: DESPERTAR
🧠

4. Trampas del Dinero

Quiz de 5 sesgos cognitivos que sabotean decisiones financieras.

FASE 1: DESPERTAR
📋

5. Mi Primer PEDEM

Framework de planificación: metas, deudas, ingresos y plan de acción.

FASE 2: DOMINIO
🤯

6. Mis Emociones

Reto de 7 días para detectar disparadores emocionales con el dinero.

FASE 2: DOMINIO
⚡

7. Reto del Flow

Programa de 7 días para activar el estado de máximo rendimiento.

FASE 3: INTEGRACIÓN

Inteligencia del Usuario

¿Qué datos captura cada actividad?

Toda esta información se almacena en la base de datos y se envía al CRM vía webhooks.

🧬

ADN Financiero

Arquetipo (ej: "Inversionista Estratégico") + Sombra (ej: "El Acumulador"). Define cómo toma decisiones con el dinero.

🐜

Gastos Hormiga

Fuga mensual en pesos/dólares + Proyección anual. Desglose por categoría de gasto.

🌡️

Termostato Financiero

Puntaje global (0-100°) + Nivel (Congelado/Tibio/Calibrado). Mide el techo invisible de riqueza.

🧠

Trampas del Dinero

5 sesgos evaluados con respuestas detalladas. Identifica qué trampas cognitivas lo afectan más.

📋

Mi Primer PEDEM

Plan completo: metas de ahorro, deudas priorizadas, balance de ingresos/egresos y plan de acción concreto.

🤯

Mis Emociones

Disparadores emocionales, patrones de comportamiento y reflexiones diarias durante 7 días.

⚡

Reto del Flow

Estado de rendimiento, reflexiones de 7 días y nivel de flow alcanzado.
